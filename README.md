# FilThreed

Sistema de búsqueda, comparación y recomendación de filamentos de impresión 3D.

## Objetivo

FilThreed busca centralizar información pública de diferentes proveedores de filamentos para facilitar la búsqueda y comparación de productos.

## Arquitectura

- Frontend: interfaz web
- Backend: API REST
- Data Pipeline: extracción y normalización automática de catálogos
- Database: almacenamiento de productos, proveedores y ofertas

## Proveedores iniciales

- Centro3D
- Bambu Lab Colombia
- Zuluprints
